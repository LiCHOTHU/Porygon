We release the training framework, the implant that runs our update inside
the official DICE-RL harness, and the exact configuration for every arm,
including the family-shared recipe and all seeds. Evaluation protocols are
stated with each table: robomimic scores are $300$-episode evaluations,
LIBERO scores use powered evaluation ($100$ rollouts $\times$ $3$ evaluation
seeds), and every reported number is an average over the stated seeds, never
a best-of. Each run fits on a single L40S or A100 GPU ($8$--$20$ hours). The
toy experiments ship as standalone scripts that regenerate
\cref{fig:intuition} and \cref{fig:toy} from scratch.
